# 大南國小－看見時間，繞著太陽走

使用 **GitHub Copilot + Zed**（以 ACP 接入 Copilot）快速在三分鐘內生成的太陽系互動 Web App(v0)。

## 版本紀錄

| 版本 | 重點內容 |
| --- | --- |
| **v0** | 使用 Copilot + Zed（ACP）在三分鐘內完成太陽系公轉動畫、速率與時間軸控制。 |
| **v1** | 新增中英文標示、地球人類速度模式，以及起床、活動、睡覺的人類動畫圖示。 |
| **final** | 完成人類與光速視角切換；地球自轉使用 NASA 公有領域影格，並會依人類、滑桿與光速模式同步播放。 |

## 功能

- 呈現太陽與八大行星的公轉動畫
- 可調整動畫運轉速率與模擬時間
- 提供地球人類速度模式，顯示真實時間、地球自轉與繞日公轉速度
- 支援播放、暫停、重設與行星資訊提示
- 可開關軌道與行星中英文標示

## 教學應用

這是一個適合小學自然科教學的互動工具。教師可透過速率控制與時間軸，帶領學生觀察行星繞日運行，理解公轉週期、軌道與太陽系的基本概念。

## 使用方式

以瀏覽器開啟 `index.html`，或在專案資料夾啟動本機靜態伺服器後瀏覽。
